# Bugfix: 目标岗位更新后推荐未刷新

## 缺陷与根因

学生修改目标岗位并保存职业画像后，前端切换到岗位推荐页，但仍保留 React 状态中的旧 `matches`。保存流程没有调用匹配接口，因此页面未依据新画像重新计算推荐。

## 修复目标

- 职业画像保存成功后立即清除旧推荐，并调用既有 `POST /api/v1/matches` 接口。
- 成功时展示基于新画像的结果与明确提示；失败时保留已保存画像并显示错误，不伪造结果。
- 保留“生成推荐”按钮，允许学生手动再次刷新。

## 非目标

- 不调整岗位排序、匹配权重、公开岗位导入或数据库历史匹配记录。
- 不修改行动计划的归属或已生成计划。

## 验收标准

1. 学生将目标岗位从 A 改为 B 并保存后，前端会重新请求匹配接口。
2. 推荐区域不会继续展示保存前的旧结果。
3. 匹配请求失败时，画像仍保存成功，页面说明需要手动重试。
4. 手动“生成推荐”仍可正常工作。
