# Bugfix: 学生演示登录卡住

## 缺陷摘要

在本地演示页点击“进入学生演示”后，按钮持续显示“进入中...”，页面未进入学生工作台。

## 复现证据

- 前端向 `POST /api/v1/demo/sessions` 发起学生演示会话请求。
- 后端请求在 10 秒内未返回。
- 数据库连通性检查返回 `OperationalError`。
- Windows 服务 `postgresql-x64-18` 状态为 `Stopped`。

## 根因

演示会话创建需要写入演示用户和脱敏审计事件。PostgreSQL 服务停止后，数据库会话无法建立，接口没有在前端可接受的时间内返回，页面保持加载状态。

## 修复目标

- 启动本地 PostgreSQL 服务，恢复既有演示会话接口。
- 保持现有 FastAPI 接口、演示身份、数据库结构和前端交互不变。
- 验证学生演示入口可获得会话并进入学生工作台。

## 非目标

- 不更换 PostgreSQL、数据库连接串或演示数据。
- 不修改 FastGPT 配置、密钥或知识库。
- 不新增浏览器端数据库连接或绕过认证的降级路径。

## 验收标准

1. `postgresql-x64-18` 服务为 `Running`。
2. `SELECT 1` 数据库连通性检查通过。
3. `POST /api/v1/demo/sessions` 在 10 秒内返回 `201`。
4. 前端点击“进入学生演示”后进入职业画像工作台。
