## 执行规则

## 任务

- [ ] **T-LOGIN-001:** 增加用户认证字段、密码重置令牌表和 Alembic 迁移。
  - 涉及文件：`backend/app/models/entities.py`、`backend/alembic/versions/`、认证测试
  - 验证标准：空库迁移成功；用户名唯一；敏感字段不进入审计。
  - 预估工程量：2-3 小时
  - 依赖：无

- [ ] **T-LOGIN-002:** 实现 scrypt 密码服务、账号查询、失败计数、锁定和会话撤销。
  - 涉及文件：`backend/app/auth/`、`backend/app/services/`
  - 验证标准：正确密码可验证；错误密码不能验证；会话过期/撤销生效。
  - 预估工程量：2-3 小时
  - 依赖：T-LOGIN-001

- [ ] **T-LOGIN-003:** 实现登录、学生注册、改密、管理员教师账号管理和管理员初始化接口。
  - 涉及文件：`backend/app/api/auth.py`、`backend/app/api/admin.py`、启动脚本
  - 验证标准：角色固定由服务端决定；非管理员不能创建教师/重置他人密码。
  - 预估工程量：3-4 小时
  - 依赖：T-LOGIN-002

- [ ] **T-LOGIN-004:** 移除演示会话入口和固定演示身份，接入现有 RBAC 与审计。
  - 涉及文件：`backend/app/api/demo.py`、`backend/app/auth/demo.py`、`backend/app/main.py`
  - 验证标准：旧 demo 端点不可用；已有学生/教师/管理员业务权限回归通过。
  - 预估工程量：1-2 小时
  - 依赖：T-LOGIN-003

- [ ] **T-LOGIN-005:** 重做前端认证入口、学生注册、首次改密、退出和会话过期处理。
  - 涉及文件：`frontend/src/components/WelcomeScreen.tsx`、`frontend/src/App.tsx`、`frontend/src/api/client.ts`
  - 验证标准：登录后按服务端角色显示页面；无角色选择器；错误和过期状态可恢复。
  - 预估工程量：3-4 小时
  - 依赖：T-LOGIN-003、T-LOGIN-004

- [ ] **T-LOGIN-006:** 增加认证、越权、锁定、改密、重置和管理员边界测试。
  - 涉及文件：`backend/tests/`、前端测试或 Playwright 流程
  - 验证标准：覆盖成功/失败登录、学生注册、教师创建、管理员禁止注册、会话撤销和 401/403。
  - 预估工程量：2-3 小时
  - 依赖：T-LOGIN-005

- [ ] **T-LOGIN-007:** 执行后端测试与 lint、前端 lint/build，并完成 Chrome 核心流程验收。
  - 涉及文件：无新增业务文件；测试报告更新至 `docs/testing/`
  - 验证标准：命令全部通过；学生注册登录、教师管理员登录、改密和管理员重置流程可操作。
  - 预估工程量：1-2 小时
  - 依赖：T-LOGIN-006
