## 2. 叙事主线

一句话：学校就业部门资源有限，用“业务同源”的多智能体仿真在投入前比较治理策略，结论统计上诚实，最终由人决策。

答辩按“问题 → 模型 → 证据 → 价值”推进：

1. 治理三问：资源投向谁、怎么投、投了有没有用。
2. 风险模型回答“投向谁”，ABM 仿真回答“怎么投”，置信区间与 V&V 回答“结论可不可信”。
3. 两条关键结论：岗位精准推送显著提升匹配率（53.4% → 56.7%）；精准帮扶不提高平均匹配率，但显著减少高风险学生（6.7 → 2.9 人）。
4. 落到系统：可运行、可审计、人工采纳。

## 5. 数字口径

PPT 中的仿真数字只能来自 `docs/deliverables/simulation-sensitivity.json`，与方案书、报名表保持一致。当前取值（模型 abm-1.0，种子 1）：

| 用途 | 数值 |
|:---|:---|
| 默认情景 | 300 人 × 16 周 × 10 次重复；教师 4 人 × 8 次/周；供给比例 0.8 |
| 初始状态 | 准备达标率 32.7%；高风险 71 人 |
| 岗位精准推送 | 匹配达成率 53.4%（51.6–55.2）→ 56.7%（55.4–58.0），+3.3 显著 |
| 精准帮扶 | 匹配 -0.2 不显著；高风险 6.7（5.0–8.4）→ 2.9（2.0–3.8），显著 |
| 技能补强培训 | 匹配 +2.1 不显著；高风险降至 2.6（1.4–3.8），显著 |
| 敏感性 | 供给 0.2 → 1.2：基线匹配 18.9% → 60.8% |
| 性能与测试 | 默认实验 5.8 秒；后端 104 项测试；500 组等价性样本 |

前置条件：R-004、R-005（随机流隔离与敏感性脚本）目前只在工作区修改、尚未提交。必须先提交并重跑脚本，确认 JSON 不再变化后再生成 PPT；若数字变化，以新 JSON 为准，第 12–14 页和本表同步更新。

表述约束（与方案书一致）：

- 置信区间重叠一律写“不显著”，不写“略有提升”。
- 每张结果页底部保留脚注：“结果基于合成群体与规则模型，用于策略相对比较，不代表真实就业预测”。
- SF-FastGPT 若仍为 mock 模式，不写“已完成真实平台联调”。
