# 就业治理智能体需求规范

> **功能名称：** 职途智航 · 高校毕业生就业治理智能体（智能社会治理赛道 · 选题（3）智能社会治理智能体）
> **版本：** v1.0
> **状态：** 待审批
> **最后更新：** 2026-10-16
> **关联文档：** `governance-agent-architecture.md` · `governance-agent-tasks.md`

## 1. 定位

参赛主题“数智赋能社会治理”。高校毕业生就业是稳就业、保民生的重点治理对象。现有系统只覆盖“学生个体自助规划”，缺少治理视角。本期把系统升级为一个就业治理智能体，按“感知 → 预警 → 仿真推演 → 决策建议 → 人工确认 → 反馈”闭环运行：

| 环节 | 能力 | 面向角色 |
|:---|:---|:---|
| 感知 | 群体就业准备度画像，聚合后脱敏 | 管理员 |
| 预警 | 可解释的就业准备度风险分级与干预清单 | 教师 |
| 仿真推演 | 基于多智能体（ABM）的毕业季就业准备过程仿真，对比不同治理策略的效果 | 管理员 |
| 决策建议 | 根据仿真结果生成策略对比报告，可选由大模型撰写解读 | 管理员 |
| 人工确认 | 管理员采纳策略并留下审计记录；系统不自动执行任何干预 | 管理员 |
| 反馈 | 教师干预记录回流到风险看板 | 教师 / 管理员 |

比赛是仿真大赛，仿真推演模块是评审重点，优先级最高。

## 2. 用户故事与验收标准

### US-G01 教师获得风险预警清单（P0）
**作为** 就业指导教师，**我希望** 看到授权学生按就业准备风险排序的清单，**以便** 优先干预最需要帮助的学生。
- **AC-G01.1：** 只返回已授权的学生。每人展示风险分（0–100）、等级（高/中/低）、各因子得分、触发原因和建议的干预动作。
- **AC-G01.2：** 风险模型只使用画像完整度、匹配得分、技能缺口、求职阶段、行动计划状态和更新时间。不使用性别、籍贯、家庭、健康、民族、政治面貌、联系方式或学号。
- **AC-G01.3：** 页面上明确标注“仅用于辅助指导，不作为评价或处分依据”。

### US-G02 管理员查看群体就业准备度画像（P1）
**作为** 就业管理员，**我希望** 按专业和求职阶段查看准备度分布、风险等级分布，以及岗位需求技能与学生技能的供需缺口，**以便** 调整课程和指导资源。
- **AC-G02.1：** 只输出聚合统计。分组人数少于 5 时合并为“其他”或隐藏（小样本抑制），永远不返回个人记录。
- **AC-G02.2：** 支持切换数据源为“真实账号数据”或“仿真合成群体”，后者在页面上标注“合成数据”。

### US-G03 管理员运行治理策略仿真（P0）
**作为** 就业管理员，**我希望** 设定群体规模、仿真周数、岗位供给和干预策略，然后运行仿真，**以便** 在投入资源之前比较不同策略的效果。
- **AC-G03.1：** 每次运行至少包含基线方案和 1–3 个干预方案。各方案使用相同的随机种子（共同随机数），每个方案重复 N 次，输出均值和 95% 置信区间。
- **AC-G03.2：** 输出逐周时间序列，包括就业准备达标率、岗位匹配达成率、高风险人数、平均技能缺口和教师工时占用，并给出 Top 技能供需缺口。
- **AC-G03.3：** 同样的参数和种子必须得到完全相同的结果（可复现）。运行参数、种子、版本号和结果要持久化，可以回看。
- **AC-G03.4：** 默认参数（300 人 × 16 周 × 4 方案 × 10 次重复）在本地 10 秒内完成。参数超过上限时返回 422。

### US-G04 智能体生成策略建议报告（P1）
**作为** 就业管理员，**我希望** 根据一次仿真结果得到策略对比结论和建议，**以便** 形成决策材料。
- **AC-G04.1：** 报告里的数值和排序全部由后端从仿真结果确定性地计算，大模型不能改动任何数字。
- **AC-G04.2：** 大模型解读（mock 或 SF-FastGPT）标注为“AI 解读，需人工审核”。平台不可用时只输出确定性报告，不报错。
- **AC-G04.3：** 管理员可以点击“采纳策略”，系统写入审计事件 `governance_strategy_adopted`，不触发任何自动操作。

### US-G05 合成数据集导出（P2）
**作为** 参赛团队，**我希望** 导出仿真合成群体和岗位市场数据集（CSV）及字段说明，**以便** 作为选题（1）“智能治理数据集”的补充成果。
- **AC-G05.1：** 导出内容只包含合成个体，与真实账号无关联，并附生成参数和种子。

## 3. 非功能需求

| ID | 类别 | 要求 |
|:---|:---|:---|
| NFR-G01 | 可解释 | 每个风险分都能拆解到因子；每个仿真指标都有公式定义（见架构文档）。 |
| NFR-G02 | 一致性 | 仿真里的智能体复用生产环境的 `MatchingService` 和风险模型，“仿真与业务同一模型”。 |
| NFR-G03 | 隐私 | 聚合时做小样本抑制（k=5）；审计不记录参数以外的内容；合成数据与真实数据隔离。 |
| NFR-G04 | 可复现 | 只用 `random.Random(seed)`，禁止使用全局随机数；结果附 `model_version`。 |
| NFR-G05 | 依赖 | 后端不新增第三方依赖（纯 Python）；前端图表用 SVG 手写，不引入图表库。 |

## 4. 超出范围

- 预测个人能否就业，或对个人作出录用/淘汰判断。
- 系统自动给学生发消息，或自动修改学生的计划。
- 接入学校生产数据，或用真实就业结果校准模型（本期只做敏感性分析和极端条件检验，见架构文档）。
