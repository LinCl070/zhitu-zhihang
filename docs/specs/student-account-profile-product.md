# 学生注册档案需求规范

> **功能名称：** 学生注册档案与入学年份选择
> **版本：** v1.0
> **状态：** 审查中
> **作者：** 项目负责人 + Codex
> **最后更新：** 2026-09-09

## 1. 概述

学生注册不再收集“显示名称”，改为采集姓名、学号、电话号码、联系邮箱和入学年份。所有新字段均为必填；学号全局唯一。姓名作为账号展示名称，教师可在其已获授权学生范围内查看联系信息，管理员可查看所有学生联系信息。

## 2. 用户故事与验收标准

### US-PROFILE-001: 完整注册档案

**作为** 新学生，**我希望** 在注册时提交学校要求的身份与联系信息，**以便** 创建可识别的学生账号。

- **AC-PROFILE-001.1:** GIVEN 学生处于注册页面，WHEN 表单显示，THEN 姓名、学号、电话号码、联系邮箱和入学年份均带红色 `*` 标识并为必填。
- **AC-PROFILE-001.2:** GIVEN 所有字段合法且学号未被使用，WHEN 提交注册，THEN 创建 `student` 账号，姓名写入账号展示名称，且保存其他档案字段。
- **AC-PROFILE-001.3:** GIVEN 学号已存在，WHEN 提交注册，THEN 返回“学号已被使用”，且不创建账号。
- **AC-PROFILE-001.4:** GIVEN 姓名、学号、电话、邮箱或年份缺失/格式非法，WHEN 提交注册，THEN 显示字段级可读错误，且不创建账号。

### US-PROFILE-002: 入学年份滚动选择

**作为** 新学生，**我希望** 通过滚动年份窗口选择入学年份，**以便** 快速准确填写而不用键盘输入年份。

- **AC-PROFILE-002.1:** GIVEN 注册页面处于学生注册模式，WHEN 入学年份控件打开，THEN 提供 `1958` 至当前自然年的年份列表。
- **AC-PROFILE-002.2:** GIVEN 用户滚动年份列表，WHEN 停止滚动，THEN 最接近中心的年份被选中并同步到提交值。
- **AC-PROFILE-002.3:** GIVEN 用户使用键盘操作控件，WHEN 按上下方向键，THEN 选中年份按一年递增或递减，范围不越界。

### US-PROFILE-003: 联系信息权限

**作为** 教师或管理员，**我希望** 在授权范围内查看学生联系信息，**以便** 完成就业指导沟通。

- **AC-PROFILE-003.1:** GIVEN 教师已被授予某学生访问权，WHEN 查看该学生摘要，THEN 可查看姓名、学号、电话号码、联系邮箱和入学年份。
- **AC-PROFILE-003.2:** GIVEN 教师未被授予某学生访问权，WHEN 调用学生摘要接口，THEN 不返回该学生及其联系信息。
- **AC-PROFILE-003.3:** GIVEN 管理员查看学生台账，WHEN 请求管理概览，THEN 可查看全部学生的上述档案字段。

## 3. 非功能性需求

| ID | 类别 | 描述 | 目标指标 |
|:---|:---|:---|:---|
| NFR-PROFILE-001 | 隐私 | 联系信息仅存于账号档案；不得进入职业画像、岗位匹配、FastGPT 请求或审计元数据。 | 相关测试覆盖所有禁止路径 |
| NFR-PROFILE-002 | 安全 | 仅学生本人、已授权教师和管理员可读取联系信息。 | 未授权返回 403 或不返回对象 |
| NFR-PROFILE-003 | 可用性 | 年份控件支持鼠标滚轮、触摸滚动及键盘操作。 | Chrome/Edge 窄屏无横向溢出 |
| NFR-PROFILE-004 | 数据质量 | 学号规范化后全局唯一。 | 数据库唯一约束 + 接口 409 |

## 4. 约束与假设

### 约束

- 所有新增字段为注册必填项，并在标签前显示红色 `*`。
- 姓名替代现有显示名称；前端和现有工作台继续读取 `display_name`，不额外保留同义字段。
- 学号必须全局唯一；手机号和联系邮箱无需唯一。
- 年份范围固定为 `1958` 至请求时所在自然年。
- 联系信息不得记录到审计事件、浏览器日志或模型提示词。

### 假设

- 学号为去首尾空白后的 10 位数字，并在规范化后全局唯一。
- 电话号码按中国大陆手机号码格式校验；联系邮箱使用标准邮箱格式校验。

## 5. 超出范围

- 手机或邮箱验证码、邮箱找回密码和通知推送。
- 教师/管理员编辑学生个人联系信息。
- 将联系方式用于岗位匹配、模型咨询或外部系统同步。
