# 缺陷修复规范 (Bugfix Specification)

> **问题名称：** SF-FastGPT 回答被错误降级为人工确认建议
> **版本：** v1.0
> **状态：** 草稿
> **严重级别：** P1
> **影响环境：** 本地演示环境（`sf_fastgpt`）
> **最后更新：** 2026-09-11

## 1. 问题概述

SF-FastGPT 官网中的两个应用可正常生成回答，但学生端“职业准备”和“就业政策”咨询均显示固定的人工确认建议。该问题阻断真实平台回答在项目内呈现，同时不能放宽对就业政策和职业建议的可追溯性要求。

## 2. 证据与复现

### 2.1 观察到的现象

- 前端连续提问后均显示“当前资料不足以确认该问题”的固定文案，并显示“回答未引用已批准资料”。
- 2026-09-11 运行 `backend.scripts.verify_fastgpt`：`career` 和 `policy` 均为 `sf_fastgpt`，但 `source_count` 均为 `0`、`sources_complete=false`，诊断退出码为 `1`。

### 2.2 复现路径

1. 以学生身份进入咨询页面，选择任一路由并提交非空问题。
2. 后端调用 SF-FastGPT 并解析到文本回答。
3. 上游响应没有被适配器归一化为来源，服务层改用固定人工确认回答。

### 2.3 影响范围

- **受影响模块：** `FastGPTClient`、`AssistantService`、学生端咨询 API 和聊天界面。
- **受影响用户：** 所有使用真实 SF-FastGPT 职业或政策咨询的已登录用户。
- **未受影响：** 岗位匹配、行动计划、教师指导、管理员台账，以及 FastGPT 官网对话本身。

## 3. 当前错误行为

### BUG-001: 未识别来源导致已生成的回答被替换

- **WHEN** SF-FastGPT 返回有效回答文本，但不使用现适配器支持的 `sources`、`sourceList` 或 `responseData.sources` 字段。
- **THEN** `AssistantService` 因空来源替换原回答，前端只能看到人工确认建议。

## 4. 修复后的期望行为

### FIX-001: 仅呈现可审核来源支持的真实回答

- **WHEN** SF-FastGPT 返回有效回答，且工作流输出或响应映射能提供每条来源的标题、链接和版本/日期。
- **THEN** 项目应显示上游回答及归一化来源，不建议转人工。

### FIX-002: 保持无来源的安全降级

- **WHEN** 上游无来源、来源字段无法映射为完整可审核来源，或平台调用失败。
- **THEN** 项目仍应显示当前人工确认建议，不展示未经核验的上游回答。

## 5. 必须保持不变的行为

### SAFE-001: 密钥与原始平台响应不出现在浏览器或日志中

- **WHEN** 调用任一路由。
- **THEN** 前端和诊断输出不得包含 API Key、应用 ID、请求头或原始响应体。

### SAFE-002: 路由隔离与既有 API 合同保持稳定

- **WHEN** 调用 `career` 或 `policy` 咨询接口。
- **THEN** 仍由服务端选择各自应用配置，并返回既有的 `answer`、`sources`、`disclaimer`、`handoff_recommended` 和 `mode` 合同。

## 6. 范围与约束

### 修复范围内

- 捕获一份脱敏的 SF-FastGPT 响应结构或由工作流明确输出来源字段。
- 将该结构中的标题、链接和版本/日期映射至统一来源模型。
- 为来源完整、来源缺失和平台异常建立定向回归测试。

### 明确不在范围内

- 绕过来源校验、直接信任无来源文本。
- 修改知识库内容、招聘数据、认证、数据库 schema 或前端视觉设计。
- 在仓库、测试夹具或文档记录真实密钥、应用 ID 或完整平台响应。

### 约束与假设

- 已确认两条路由在 `detail: true` 下均只返回 OpenAI 兼容的 `choices[0].message.content`；`responseData` 为空且没有任何来源容器。因此当前工作流未将知识库引用输出到 Chat Completions API，并非现有适配器遗漏了已返回字段。
- 来源的标题、可访问链接和版本/日期均为必填；缺一项即视为不合格。

## 7. 风险与回滚提示

- **主要风险：** 错误放宽来源校验会把不可追溯的就业信息包装为可信建议。
- **回滚方式：** 回退适配器改动或停用工作流来源输出；空来源将自动回到现有人工确认路径。
- **观察指标：** 两路诊断的来源数量、来源完整性和通过状态；不记录回答正文。
