# 需求规范 (Product Specification)

> **功能名称：** 职途智航 - 高校就业择业规划智能体
> **版本：** v1.0
> **状态：** 已由 `docs/specs/design.md` 与 `docs/specs/requirements.md` 补充修订
> **作者：** AI Architect + Human Engineer
> **最后更新：** 2026-07-21

## 1. 概述

职途智航面向高校学生、就业指导教师和就业管理员，帮助学生将零散的专业、技能、项目经历、求职意向转化为可解释的职业画像、岗位建议和行动计划。系统使用 SF-FastGPT 完成就业政策、行业资料和岗位说明的检索与工作流编排；岗位匹配分由后端规则计算，不由大模型单独决定。

首版通过脱敏学生画像和模拟岗位库展示“职业诊断 - 岗位匹配 - 能力差距 - 求职计划 - 教师协助”的完整闭环，不承诺录用结果，也不替代学校就业指导或招聘单位的最终决定。

## 2. 用户故事与验收标准

### US-001: 学生建立职业画像

**作为** 学生，**我希望** 填写自己的专业、技能、项目经历和求职偏好，**以便** 获得适合进一步分析的职业画像。

#### 验收标准

- **AC-001.1:** GIVEN 学生使用演示账号，WHEN 填写专业、技能、项目、目标岗位/城市和求职阶段，THEN 系统保存最小化脱敏画像并展示结构化摘要。
- **AC-001.2:** GIVEN 学生未填写必要字段，WHEN 发起岗位匹配，THEN 系统明确提示需要补充的信息，不根据家庭背景、性别、籍贯或健康信息推断画像。

### US-002: 学生获得可解释的岗位匹配

**作为** 学生，**我希望** 获得岗位建议及其匹配理由，**以便** 理解自己适合的方向和能力差距。

#### 验收标准

- **AC-002.1:** GIVEN 学生职业画像和已发布岗位，WHEN 发起匹配，THEN 系统返回 3 至 5 个岗位、规则匹配分、匹配理由、缺失技能和岗位来源。
- **AC-002.2:** GIVEN 某岗位数据过期、来源不明或无可用岗位，WHEN 系统处理匹配，THEN 系统排除该岗位或明确说明数据不足，不编造招聘信息。

### US-003: 学生获得求职行动计划

**作为** 学生，**我希望** 根据目标岗位获得阶段性行动计划，**以便** 有序完成简历、技能补强、投递和面试准备。

#### 验收标准

- **AC-003.1:** GIVEN 学生选择目标岗位，WHEN 生成计划，THEN 系统输出时间分段的待办、优先级、关联差距和可引用的学习/就业资料。
- **AC-003.2:** GIVEN 知识库无足够依据，WHEN 系统无法推荐具体资料，THEN 仅输出通用行动框架并建议向就业指导教师咨询。

### US-004: 学生咨询就业政策与岗位信息

**作为** 学生，**我希望** 咨询就业政策、招聘流程和岗位要求，**以便** 获得有来源的办理或准备建议。

#### 验收标准

- **AC-004.1:** GIVEN 用户提问，WHEN SF-FastGPT 检索到已批准资料，THEN 回答展示资料标题、版本或发布日期。
- **AC-004.2:** GIVEN 资料不足、问题涉及录用承诺或个体资格判断，WHEN 智能体无法确认，THEN 转人工且不编造结论。

### US-005: 就业指导教师提供人工协助

**作为** 就业指导教师，**我希望** 查看授权学生的职业目标和待协助事项，**以便** 提供针对性建议。

#### 验收标准

- **AC-005.1:** GIVEN 教师已登录，WHEN 查看学生工作台，THEN 仅展示被授权学生的职业摘要、行动计划和人工协助请求。
- **AC-005.2:** GIVEN 教师提交指导意见，WHEN 学生打开对应计划，THEN 可查看该意见和记录时间。

### US-006: 就业管理员维护可信资料

**作为** 就业管理员，**我希望** 管理岗位数据和知识资料的状态，**以便** 保证推荐结果可追溯。

#### 验收标准

- **AC-006.1:** GIVEN 管理员查看资料台账，WHEN 某资料或岗位缺少来源、发布日期或有效状态，THEN 不允许其进入 SF-FastGPT 知识库或推荐结果。
- **AC-006.2:** GIVEN 管理员查看审计记录，WHEN 查询关键操作，THEN 只能看到脱敏事件，不显示完整学生画像、联系方式或平台密钥。

## 3. 非功能性需求

| ID | 类别 | 描述 | 目标指标 |
|:---|:---|:---|:---|
| NFR-001 | 可解释性 | 每条推荐展示规则分、关键匹配项、缺口和来源。 | 100% 推荐结果含解释字段 |
| NFR-002 | 隐私 | 演示默认使用脱敏画像和模拟岗位；不处理家庭、医疗、性别、籍贯等敏感或歧视性字段。 | 敏感字段不进入数据库、日志或提示词 |
| NFR-003 | 安全 | 服务端执行角色和资源归属校验，SF-FastGPT 密钥只在服务端保存。 | 越权请求返回 403 并产生审计 |
| NFR-004 | 可追溯 | 政策和岗位数据必须有来源、版本/发布日期和状态。 | 无依据时拒绝引用或推荐 |
| NFR-005 | 性能 | 页面与本地 API 快速响应；模型调用提供加载状态。 | 本地 API P95 < 1 秒；完整对话目标 P95 < 15 秒 |
| NFR-006 | 兼容性 | 支持最新 Chrome、Edge 与移动端窄屏。 | 核心页面无水平溢出 |

## 4. 约束与假设

### 约束

- 必须使用赛事提供的 SF-FastGPT 作为知识库和 Agent 工作流平台。
- 首版仅做职业规划和求职辅助，不与学校就业系统、招聘平台或企业招聘系统写回集成。
- 岗位匹配分使用确定性规则计算；大模型仅解释和规划，不能给出录用承诺或淘汰判断。
- 真实学生数据、就业资料和 SF-FastGPT 平台凭据须获得授权后才能接入。

### 假设

- 开发阶段使用 3 个脱敏演示学生、10 至 20 条带来源的模拟岗位和经审核的就业资料。
- 后续可从学校就业中心、国家大学生就业服务平台或经授权的招聘来源获得岗位和政策资料。
- 项目使用 React + TypeScript、FastAPI 和 PostgreSQL 进行演示；连接串仅由本地 `.env` 或部署环境提供。

## 5. 超出范围 (Out of Scope)

- 自动投递简历、自动预约面试、代表学生与企业沟通或承诺录用结果。
- 基于性别、籍贯、家庭状况、健康信息、民族或政治面貌进行筛选或推荐。
- 对接生产就业系统、获取真实学生档案、抓取未经授权的招聘数据。
- 自动代写虚假项目经历、学历、技能证书或其他求职材料。
