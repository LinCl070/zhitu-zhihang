# 需求规范 (Requirements Derived from Design)

> **功能名称：** 职途智航 PostgreSQL 持久化
> **来源设计：** `docs/specs/design.md`
> **版本：** v1.0
> **状态：** 已批准
> **最后更新：** 2026-07-21

## 1. 概述

本规范从 PostgreSQL 持久化设计派生。它为职业画像、岗位、匹配结果、行动计划和审计提供可迁移、可验证的数据库基础，同时保持模拟数据、最小权限和敏感信息边界。

## 2. 功能需求与验收标准

### REQ-DB-001: PostgreSQL 配置与连接边界

**作为** 项目维护者，**我希望** 通过环境变量配置 PostgreSQL，**以便** 在不同环境中安全连接数据库。

- **AC-DB-001.1:** GIVEN `.env` 配置了有效 PostgreSQL `DATABASE_URL`，WHEN 应用启动，THEN 后端可以建立受控数据库连接，且不会在响应或日志中返回连接串。
- **AC-DB-001.2:** GIVEN `DATABASE_URL` 缺失或协议不是 PostgreSQL，WHEN 应用启动，THEN 启动失败并给出不含密钥的配置错误。

### REQ-DB-002: 可版本化 schema 与迁移

**作为** 项目维护者，**我希望** 从空数据库创建和升级 schema，**以便** 保证演示与部署环境一致。

- **AC-DB-002.1:** GIVEN 空的 PostgreSQL 数据库，WHEN 执行迁移升级，THEN 创建用户、画像、岗位、匹配、计划和审计相关表、索引与枚举。
- **AC-DB-002.2:** GIVEN 已应用过迁移的数据库，WHEN 重复执行升级，THEN 不破坏既有数据且 schema 版本保持一致。

### REQ-DB-003: 数据模型与隐私边界

**作为** 演示用户，**我希望** 系统仅保存职业规划所需的脱敏字段，**以便** 避免非必要个人信息进入数据库。

- **AC-DB-003.1:** GIVEN 演示画像或岗位数据，WHEN 保存，THEN 使用 UUID、JSONB、受控状态字段和时间字段，并满足 `product.md` 的禁止字段约束。
- **AC-DB-003.2:** GIVEN 需要写入审计事件，WHEN 保存，THEN 只记录角色、操作、资源标识和时间，不保存完整画像、简历或连接串。

## 3. 非功能性需求

| ID | 类别 | 描述 | 来源设计约束 |
|:---|:---|:---|:---|
| NFR-DB-001 | 安全 | `DATABASE_URL` 只存在于部署环境或 `.env`，不写入仓库或日志。 | `design.md` 2.2 |
| NFR-DB-002 | 一致性 | 写入业务对象和审计事件使用同一受控事务。 | `design.md` 4.1 |
| NFR-DB-003 | 可维护性 | 所有 schema 变更必须经 Alembic 迁移。 | `design.md` 4.1、4.3 |
| NFR-DB-004 | 性能 | 演示环境的连接池不超过 5 个持久连接。 | `design.md` 2.3 |
| NFR-AUTH-001 | 安全 | 演示会话令牌仅在后端内存保存，服务重启或 8 小时后失效。 | `design.md` 4.5 |
| NFR-AUTH-002 | 隐私 | 审计不保存请求体、画像、令牌或连接串。 | `design.md` 4.5 |

### REQ-AUTH-001: 演示会话与角色校验

**作为** 演示参与者，**我希望** 使用受控的合成身份进入系统，**以便** 展示不同角色的可见范围而不处理真实账户密码。

- **AC-AUTH-001.1:** GIVEN 合成学生、教师或管理员身份，WHEN 创建演示会话，THEN 返回短期 Bearer 令牌，且令牌不写入数据库或审计记录。
- **AC-AUTH-001.2:** GIVEN 请求缺少、携带无效或过期令牌，WHEN 调用受保护接口，THEN 返回 401。
- **AC-AUTH-001.3:** GIVEN 角色访问不允许的端点，WHEN 服务端处理请求，THEN 返回 403 并写入脱敏审计事件。

### REQ-AUTH-002: 资源归属与教师授权

**作为** 学生和就业指导教师，**我希望** 职业资料只在对应的归属或授权范围内可见，**以便** 避免演示数据越权访问。

- **AC-AUTH-002.1:** GIVEN 学生访问他人的画像或行动计划，WHEN 服务端校验资源归属，THEN 返回 403 并写入脱敏审计事件。
- **AC-AUTH-002.2:** GIVEN 教师没有对应学生的授权记录，WHEN 读取其画像，THEN 返回 403；有记录时才允许读取。

### REQ-MATCH-001: 可解释的确定性岗位匹配

**作为** 学生，**我希望** 获得由固定规则计算的岗位分数，**以便** 理解推荐原因，而不是接受不可复现的主观判断。

- **AC-MATCH-001.1:** GIVEN 职业画像和岗位库，WHEN 计算匹配，THEN 只返回 `published` 且未过期、来源标题存在的岗位。
- **AC-MATCH-001.2:** GIVEN 可匹配岗位，WHEN 返回结果，THEN 每条结果总分为 0 至 100，并包含技能、专业、项目、城市、目标岗位五个分项、能力缺口和来源。
- **AC-MATCH-001.3:** GIVEN 相同画像、岗位和计算日期，WHEN 重复计算，THEN 分数、缺口和排序完全相同，且不会调用 FastGPT 或写入数据库。

### REQ-FASTGPT-001: 统一的智能咨询客户端

**作为** 系统维护者，**我希望** 模拟和真实 SF-FastGPT 调用使用同一响应契约，**以便** 在演示和平台联调之间安全切换。

- **AC-FASTGPT-001.1:** GIVEN `FASTGPT_MODE=mock`，WHEN 请求职业或政策咨询，THEN 返回统一回答、来源、免责声明和转人工字段，且不发起网络请求。
- **AC-FASTGPT-001.2:** GIVEN `FASTGPT_MODE=sf_fastgpt` 且配置完整，WHEN 请求职业或政策咨询，THEN 服务端按对应工作流 ID 调用可配置的聊天补全路径，并归一化回答与来源。
- **AC-FASTGPT-001.3:** GIVEN 配置缺失、平台请求失败、格式异常或缺少来源，WHEN 服务端处理咨询，THEN 返回不含密钥和原始平台内容的转人工结果。
- **AC-FASTGPT-001.4:** GIVEN 任意浏览器响应或审计事件，WHEN 返回或持久化，THEN 不包含 API Key、工作流 ID、原始请求头或原始平台响应。

### REQ-API-001: 学生职业规划闭环接口

**作为** 学生，**我希望** 在受保护的接口中维护画像、查看匹配、生成计划与发起咨询，**以便** 完成可演示的职业规划流程。

- **AC-API-001.1:** GIVEN 已登录学生，WHEN 创建或更新自己的画像，THEN 仅保存允许的脱敏字段并产生审计事件。
- **AC-API-001.2:** GIVEN 画像完整，WHEN 发起匹配，THEN 返回 3 至 5 条规则结果并持久化总分、分项、缺口与来源关联；无可信岗位时返回空列表与人工咨询建议。
- **AC-API-001.3:** GIVEN 学生选择自己的匹配结果，WHEN 生成行动计划，THEN 返回阶段性、可执行的待办，不承诺录用或伪造资料。
- **AC-API-001.4:** GIVEN 任意角色咨询就业问题，WHEN 资料不足或模型不可用，THEN 返回安全降级与人工确认建议，且请求不含未经授权的画像内容。

### REQ-STAFF-001: 教师协助与管理员工作台

**作为** 就业指导教师和管理员，**我希望** 在严格角色范围内查看协助事项、提交意见和维护可信资料，**以便** 支持学生而不扩大敏感数据访问面。

- **AC-STAFF-001.1:** GIVEN 教师已被授权给某学生，WHEN 查看协助工作台，THEN 只返回该学生的职业摘要、行动计划状态和教师本人意见；无授权学生不得出现在列表中。
- **AC-STAFF-001.2:** GIVEN 授权教师提交指导意见，WHEN 系统保存，THEN 意见关联学生和行动计划、长度受限并产生脱敏审计事件。
- **AC-STAFF-001.3:** GIVEN 管理员查看工作台，WHEN 读取岗位、资料或审计，THEN 只返回审核与追溯字段；不得返回密钥、连接串、完整画像或意见正文。

## 5. 约束、假设与超出范围

### 约束

- 只支持 PostgreSQL，不保留 SQLite 回退。
- 只连接本地或经批准的演示数据库，不连接学校生产数据库。

### 假设

- 项目负责人会在实施 T-003 前提供可用的本地 PostgreSQL 服务和 `DATABASE_URL`。

### 超出范围

- 生产高可用、数据库备份、跨区域复制、真实学校数据迁移和自动数据同步。
