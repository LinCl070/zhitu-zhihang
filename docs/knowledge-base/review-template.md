# 就业资料审核记录

每份政策、岗位或职业发展资料应复制本模板，审核结论同步回填 `source-registry.csv`。

| 字段 | 内容 |
|:---|:---|
| 资料 ID | `SRC-XXX-000` |
| 标题 | 待填写 |
| 类型 | 就业政策 / 岗位信息 / 职业发展资料 |
| 来源链接或受控文件路径 | 待填写 |
| 提供或负责部门 | 待填写 |
| 版本、文号或发布日期 | 待填写 |
| 有效期 | 待填写 |
| 适用范围 | 待填写 |
| 审核人和日期 | 待填写 |
| 审核结论 | 待审核 / 已批准 / 退回补充 / 已失效 |

## 审核清单

- [ ] 来源、发布部门、日期和有效期可核验。
- [ ] 岗位或政策的适用范围清晰，不含误导性承诺。
- [ ] 已删除学生名单、简历、联系方式、企业联系人、内网地址和密钥。
- [ ] 内容未要求系统自动投递、自动面试或自动筛选学生。
- [ ] 资料可分段检索，标题、版本和关键条款能作为回答引用。
- [ ] 已记录失效后的下线负责人。

未通过审核的资料不得进入 SF-FastGPT，也不得用于岗位推荐和行动计划。
