# CUIT 求职准备知识库上传包

本目录中的三份 Word 文档面向成都信息工程大学学生的求职准备场景，由项目组依据公开官方资料整理，适合上传到 `CUIT就业求职准备知识库`。

| 文件 | 覆盖主题 | 当前审核状态 |
|:---|:---|:---|
| `01-求职简历准备指南.docx` | 定向简历、经历表达、隐私边界、投递前检查 | 已上传 |
| `02-校招网申与笔试准备指南.docx` | 网申、测评、笔试、限时模拟与复盘 | 已上传 |
| `03-面试准备与求职风险防范指南.docx` | 企业与岗位调研、模拟面试、招聘核验与防骗 | 已上传 |
| `04-高校毕业生就业政策与办事服务指南.docx` | 就业登记、求职创业支持、基层项目与权益保障 | 已上传 |
| `05-就业求职准备与招聘风险防范指南.docx` | 岗位核验、经历证据、面试复盘与防骗提醒 | 已上传 |
| `06-Docker基础与岗位技能准备指南.docx` | 核心概念、Dockerfile规范、多服务编排与缺口补齐 | 已批准 |

上传前由项目负责人确认每份文档首页列出的原始链接可访问、发布日期和适用范围无误，再将 `docs/knowledge-base/source-registry.csv` 中对应资料的 `status` 改为 `approved`、`fastgpt_upload_eligible` 改为 `true`，并填写审核人和审核日期。

上传后在工作流中要求：优先引用资料标题和链接；资料未覆盖时建议向学校就业指导部门确认；不得承诺录用、薪酬、资格或招聘结果。

三份 Word 文件已通过 OOXML 结构校验。当前电脑未检测到可用的 LibreOffice 或 Word 转换程序，无法完成页面渲染检查；上传前请在本机 Word 中打开并快速确认排版。
