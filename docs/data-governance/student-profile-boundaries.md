# 演示学生画像边界

首版仅创建 3 个脱敏演示画像。每个画像只可包含：专业、求职阶段、技能标签、脱敏项目摘要、目标岗位、目标城市和自愿填写的工作偏好。

## 允许字段

| 字段 | 用途 | 示例 |
|:---|:---|:---|
| 专业 | 岗位相关度参考 | 软件工程 |
| 技能标签 | 技能匹配和差距分析 | Python、SQL、Git |
| 项目摘要 | 项目经验匹配 | 数据看板课程项目 |
| 目标岗位与城市 | 岗位排序 | 后端开发、成都 |
| 求职阶段 | 计划节奏 | preparing |

## 禁止字段

- 姓名、学号、电话、邮箱、住址、身份证号和完整简历附件。
- 性别、籍贯、民族、政治面貌、婚育状态、家庭经济情况、健康/医疗信息。
- 完整成绩单、处分记录、心理测评和未获授权的教师评价。

## 演示账号命名

使用 `student-demo-a`、`student-demo-b`、`student-demo-c` 等代号。页面与录像中不得出现可识别真实个人的信息。
