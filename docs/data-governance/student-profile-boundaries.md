# 演示学生画像边界

职业画像仅包含专业、求职阶段、技能标签、脱敏项目摘要、目标岗位、目标城市和自愿填写的工作偏好。学生账号档案与职业画像分离保存，并遵循下方的授权边界。

## 账号档案字段

学生注册时可保存姓名、学号、电话号码、联系邮箱和入学年份，用于账号识别和就业指导联系：

- 学生只能读取本人账号档案。
- 教师只能读取已获管理员授权学生的账号档案。
- 管理员可以读取所有学生账号档案。
- 这些字段不得进入职业画像、岗位匹配、行动计划、FastGPT 请求、审计元数据或公开注册响应。

## 允许字段

| 字段 | 用途 | 示例 |
|:---|:---|:---|
| 专业 | 岗位相关度参考 | 软件工程 |
| 技能标签 | 技能匹配和差距分析 | Python、SQL、Git |
| 项目摘要 | 项目经验匹配 | 数据看板课程项目 |
| 目标岗位与城市 | 岗位排序 | 后端开发、成都 |
| 求职阶段 | 计划节奏 | preparing |

## 禁止字段

- 住址、身份证号和完整简历附件。
- 性别、籍贯、民族、政治面貌、婚育状态、家庭经济情况、健康/医疗信息。
- 完整成绩单、处分记录、心理测评和未获授权的教师评价。

## 演示账号命名

演示账号使用虚构姓名、学号、电话和邮箱。页面与录像不得出现真实个人信息。
