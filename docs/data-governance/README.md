# 职途智航数据治理

本目录管理首版演示使用的岗位与学生画像数据。系统区分三类数据：

- `模拟演示数据`：项目组创建，仅用于功能验证和录屏，不可表述为真实招聘信息。
- `待审核资料`：已登记但尚未核验来源、版本或使用权限，不可用于推荐或上传 SF-FastGPT。
- `已批准资料`：来源、日期、适用范围和负责人已完成审核，可按权限用于推荐或知识检索。

真实学生档案、完整简历、联系方式、家庭情况、健康信息、性别、籍贯、民族、政治面貌和未经授权的招聘数据均不得进入本目录、数据库、日志或模型提示词。

只有带有来源 ID、发布日期、有效期、状态和适用范围的数据才可被后续服务读取。岗位失效、来源撤回或资料修订后，必须立即停止推荐并更新台账。
