# 职途智航——高校毕业生就业治理智能体仿真作品方案书

> 赛道：智能社会治理赛道 · 选题（3）智能社会治理智能体
> 项目名称：职途智航——高校毕业生就业治理智能体
> 所在单位：成都信息工程大学

## 摘要

高校毕业生就业是"稳就业、保民生"的重点治理对象。现有就业服务系统普遍聚焦于学生个体的自助规划，缺少面向学校层面的治理视角，难以回答"把有限的指导资源投到哪、不同干预策略效果如何、如何可解释地预警"等问题。本作品将就业服务系统升级为一个就业治理智能体，按"感知→预警→仿真推演→决策建议→人工确认→反馈"的闭环运行：以可解释的风险模型对学生就业准备度分级预警，以多智能体仿真（ABM）对比不同治理策略的效果，以确定性策略报告辅助决策，并通过人工采纳与审计保证可追溯、不自动干预。

系统在模型层做到"仿真与业务同一模型"：仿真的合成学生复用生产环境的岗位匹配评分器与风险模型，保证推演结果与真实业务口径一致。模型检验采用共同随机数、确定性检验与极端条件检验三重保障，敏感性分析采用一次只改一个参数（OAT）方法对岗位供给比例、教师数量与学习率逐项扫描。在默认参数（300 人 × 16 周 × 10 次重复）下，仿真在本地约 2 秒内完成，精准帮扶策略使终点匹配达成率较基线提升约 6.3 个百分点。本作品为高校就业治理提供了一套可解释、可复现、可审计的决策支持工具。

## 引言

就业是最大的民生工程。随着高校毕业生规模持续扩大，就业指导资源有限与个体需求多样化之间的矛盾日益突出。传统就业服务依赖人工经验和事后统计，存在三重不足：其一，风险识别依赖主观判断，缺乏可解释、可量化的分级标准；其二，干预策略的效果难以在投入资源前预先评估，试错成本高；其三，数据驱动的决策过程缺乏透明度与可追溯性，容易引发公平性与隐私关切。

针对上述问题，本作品将多智能体仿真技术引入就业治理场景，构建一个面向高校就业管理员的决策支持智能体。系统以"感知—预警—仿真推演—决策建议—人工确认—反馈"为闭环，通过可解释风险模型、ABM 仿真引擎与确定性报告，把就业治理从"经验驱动"升级为"模型辅助、人工决策"，在提升决策科学性的同时严守隐私与伦理边界。

## 研究背景及意义

### 背景

（1）就业治理的现实需求。高校就业工作涉及专业设置、课程调整、指导资源配置等多个决策环节，管理者需要在有限的教师、岗位和培训资源下做出取舍。缺乏量化手段时，资源分配往往依赖直觉或惯性。

（2）仿真技术的成熟。基于智能体建模（Agent-Based Modeling, ABM）的社会仿真已在交通、流行病、公共政策等领域广泛应用，通过自底向上的个体行为规则涌现出宏观规律，适合刻画"学生个体行为—教师干预—群体就业结果"的复杂互动。

（3）可解释性与隐私的监管要求。就业治理涉及学生敏感信息，风险分级和决策建议必须可解释、可追溯，且不得使用性别、籍贯、健康等受保护属性。

### 意义

（1）理论意义：将 ABM 与可解释风险模型结合，为"智能社会治理智能体"提供了一种可复现的建模范式，即"业务模型与仿真模型同源、规则透明、结果可检验"。

（2）实践意义：为高校就业管理者提供"投什么、投多少、效果如何"的量化依据，帮助其把有限资源投向风险最高的学生与缺口最大的技能，实现精准治理。

（3）伦理意义：通过小样本抑制、审计脱敏、人工确认等机制，展示"数据驱动的治理"与"隐私保护的治理"可以并行不悖。

## 研究内容与方案

### 1. 总体架构

系统分为感知、预警、仿真推演、决策建议、人工确认五个层次：

- **感知**：聚合学生职业画像，形成群体就业准备度画像（按专业×阶段聚合，小样本抑制）；
- **预警**：可解释风险模型对学生就业准备度分级，输出因子得分与干预清单；
- **仿真推演**：多智能体仿真对比不同治理策略的群体效果；
- **决策建议**：确定性策略报告，可选大模型解读（大模型不产生数字）；
- **人工确认**：管理员采纳策略并写入审计，系统不自动执行任何干预。

### 2. 风险模型

风险模型是纯函数 `assess_risk(RiskInput) -> RiskAssessment`，输入为不含敏感字段的纯数据类 `RiskInput`，输出总分（0–100）、等级与干预清单。

**因子定义**（权重合计 100）：

| 因子 | 满分 | 规则 |
|:---|:---|:---|
| profile（画像） | 25 | 无画像记 25；技能少于 3 项或无项目记 10；否则 0 |
| match（匹配） | 25 | 最高匹配分 ≥70 记 0；50–69 记 12；低于 50 或无匹配记 25 |
| gap（技能缺口） | 15 | min(15, 5 × 缺口技能数) |
| stage（求职阶段） | 20 | exploring 且距毕业 ≤12 个月记 20；preparing 且 ≤6 个月记 12；毕业时间未知但处于 exploring 记 10；否则 0 |
| plan（行动计划） | 10 | 无行动计划记 10 |
| stale（画像更新） | 5 | 画像超过 30 天未更新记 5 |

**等级阈值**：总分 ≥60 为高风险，35–59 为中风险，<35 为低风险。每个非零因子对应一条原因和一条建议干预。

风险分只用于辅助指导，明确标注"不作为评价或处分依据"，且不使用性别、籍贯、家庭、健康、民族、政治面貌、联系方式或学号。

### 3. ABM 仿真模型

**合成群体**：从已发布的模拟/公开岗位模板生成岗位市场，岗位容量按 `ceil(群体规模 × 供给比例 / 模板数)` 分配。合成学生 `StudentAgent` 用确定性随机数生成，专业从岗位偏好专业并集抽取，技能初始 2–5 项，学习率、主动性、求职阶段按给定分布初始化。智能体 id 统一为 `syn-{index}`，与真实账号无关联。

**评分**：实现 `FastScorer`，预计算岗位归一化技能集、专业集与项目信号词表，计分规则与权重直接引用生产 `matching.py` 的常量（技能 50、专业 20、项目 15、城市 5、目标岗位 10），不另写数值，保证与 `MatchingService` 完全等价（经 500 组随机样本验证分数一致）。

**逐周推进**（顺序固定）：

1. **教师服务**：可用会话数 = 教师数 × 每周会话数（默认 4×8）。基线随机选取，"精准帮扶"选风险分最高者。被服务学生主动性 +0.15（上限 1.0），exploring 直接进入 preparing；
2. **学生行动**（概率为主动性）：exploring 以 0.3 概率进入 preparing；preparing 以学习率习得目标岗位缺口技能（技能培训再加 +0.2 boost），最佳匹配 ≥60 进入 applying；applying 投递最佳匹配岗位，分数 ≥60 且容量充足时记为匹配达成；
3. **时间推进**：距毕业月数每周减 0.25，实时更新风险分。

**治理策略**（5 个场景）：

| 场景 | 名称 | 参数改变 |
|:---|:---|:---|
| baseline | 现状基线 | 教师随机服务 |
| skill_training | 技能补强培训 | 前 30% 最大缺口学生训练加成 +0.2 |
| precision_coaching | 精准帮扶 | 教师按风险分排序服务 |
| job_push | 岗位精准推送 | 跨城市岗位全部可见 |
| combined | 组合策略 | 以上三项同时生效 |

**指标定义**（逐周输出）：就业准备达标率（最佳匹配 ≥60 占比）、岗位匹配达成率（matched 占比）、高风险人数、平均技能缺口、教师工时占用率。汇总结果含终点周各指标均值与 95% 置信区间（`mean ± 1.96·sd/√n`）、相对基线提升幅度、Top 10 技能供需缺口。

### 4. 实验设计与模型检验

- **共同随机数**：第 r 次重复对所有场景使用 `seed + r`，保证对比公平；
- **确定性检验**：同样参数运行两次结果逐字段相等；
- **极端条件检验**：`supply_ratio=0` 时匹配达成率恒为 0；`counselor_count=0` 时工时占用为 0 且"精准帮扶"等于"基线"；学习率为 0 且全员处于 exploring 时准备达标率不上升；
- **参数上限**：群体规模 50–1000（默认 300）、周数 4–26（默认 16）、重复 1–20（默认 10），默认参数本地 ≤10 秒完成。

### 5. 敏感性分析

采用 OAT 方法对岗位供给比例、教师数量、学习率逐项扫描，结果（数字来自脚本 `scripts/simulation_sensitivity.py` 实际输出）如下：

| 参数 | 取值 | 基线匹配达成率 | 精准帮扶达成率 | 提升幅度 |
|:---|:---|:---|:---|:---|
| 基线 | — | 38.3% | 44.6% | +6.3 |
| 岗位供给比例 | 0.2 / 0.5 / 0.8 / 1.2 | 18.0% / 33.4% / 38.3% / 41.1% | 18.8% / 37.2% / 44.6% / 47.9% | +0.8 / +3.8 / +6.3 / +6.8 |
| 教师数量 | 0 / 2 / 4 / 8 | 36.4% / 37.1% / 38.3% / 40.2% | 36.4% / 42.1% / 44.6% / 48.0% | +0.0 / +4.9 / +6.3 / +7.7 |
| 学习率 | 0.15 / 0.3 / 0.45 | 30.0% / 39.9% / 45.3% | 32.3% / 45.1% / 52.1% | +2.3 / +5.2 / +6.8 |

敏感性分析表明：岗位供给越紧张，精准帮扶的相对提升越明显；教师数量增加有正收益但边际递减；学习率提升能显著改善最终匹配达成率。这些结果为资源分配提供了量化依据。

## 特色与创新之处

1. **业务与仿真同源模型**：仿真中的合成学生复用生产环境的岗位匹配评分器与风险模型，避免了"仿真一套、业务一套"的口径偏差，保证推演结论可直接映射到真实治理决策。

2. **可解释的就业准备度风险模型**：风险分可逐因子拆解（画像、匹配、缺口、阶段、计划、更新），每个非零因子对应明确的干预动作，不依赖黑箱模型，且不使用任何受保护属性。

3. **三重模型检验保障可信度**：共同随机数保证策略对比公平，确定性检验保证可复现，极端条件检验验证模型在边界情形下的行为合理性，敏感性分析揭示关键参数的稳健性。

4. **治理闭环中的人工确认机制**：仿真结论只作为决策建议，管理员采纳策略写入审计事件，系统不自动给学生发消息或修改计划，体现"模型辅助、人工决策"的治理伦理。

5. **隐私与安全内建**：聚合统计做小样本抑制（k=5），风险接口不回显学号与联系方式，审计不记录完整参数与结果，合成数据与真实数据隔离。

## 总结

本作品面向高校毕业生就业治理这一现实场景，构建了一个以多智能体仿真为核心的就业治理智能体。系统以可解释风险模型实现就业准备度的分级预警，以 ABM 仿真对比多种治理策略的群体效果，以确定性报告辅助决策，并通过人工确认与脱敏审计保证可追溯、不越界。模型经三重检验与敏感性分析验证，具备可复现性与可解释性，为高校就业管理者提供了一套科学、可信、合规的决策支持工具。

后续工作方向包括：接入真实就业结果对模型做长期校准（在合规前提下）、扩展更多治理策略与群体异质性刻画，以及将仿真能力沉淀为可复用的社会治理仿真框架。
